AIChat API 前端接入文档

两个独立云函数：LoginService 负责短信登录和 JWT，ChatService 负责角色、聊天、天气和历史。

服务Base URL线上版本
LoginServicehttps://aichat-login-kemznyglgb.cn-hangzhou.fcapp.run2026.06.10-jwt.1
ChatServicehttps://aichat-chat-nitnspniec.cn-hangzhou.fcapp.run2026.06.10-auth-chat.1

接入流程

  1. 发送短信验证码。
  2. 验证码登录并保存 JWT。
  3. 公开获取角色。
  4. 携带 JWT 聊天、读取历史或清空聊天。
Authorization: Bearer <accessToken>

通用约定

JSON 请求使用 Content-Type: application/json。前端应使用稳定的 code 判断错误。

{
  "success": false,
  "code": "INVALID_INPUT",
  "message": "中文错误说明",
  "details": {}
}

LoginService

POST/send-code 无需 JWT

字段类型必填说明
countryCodestring否默认 86，当前仅支持中国大陆
phoneNumberstring是中国大陆手机号
{
  "countryCode": "86",
  "phoneNumber": "13800138000"
}
{
  "success": true,
  "message": "验证码已发送",
  "data": {
    "bizId": "provider-biz-id",
    "expiresIn": 300,
    "retryAfter": 60
  }
}

POST/login 无需 JWT

字段类型必填说明
countryCodestring否默认 86
phoneNumberstring是中国大陆手机号
verifyCodestring是4 至 8 位数字或字母
{
  "countryCode": "86",
  "phoneNumber": "13800138000",
  "verifyCode": "1234"
}
{
  "success": true,
  "message": "登录成功",
  "data": {
    "accessToken": "<JWT>",
    "tokenType": "Bearer",
    "expiresIn": 2592000,
    "user": {
      "id": 1,
      "countryCode": "86",
      "phoneNumber": "13800138000"
    }
  }
}

ChatService

GET/roles 无需 JWT

{
  "success": true,
  "data": {
    "roles": [{
      "id": 1,
      "key": "naitang",
      "nickname": "奶糖",
      "description": "猫咪系陪伴角色",
      "avatarUrl": "https://...",
      "backgroundUrl": "https://..."
    }]
  }
}

POST/chat 需要 JWT

字段类型必填说明
roleIdnumber是角色 ID
messagestring条件必填与 image 至少提供一个
imagestring条件必填JPEG/PNG/WebP Base64 Data URL，默认最大 6MB
streamboolean否默认 true
{
  "roleId": 1,
  "message": "杭州今天天气怎么样？",
  "stream": true
}
客户端不能提交完整 messages、系统 Prompt 或模型名。图片不持久化，也不会进入下一轮上下文。

非流式响应

{
  "success": true,
  "data": {
    "conversationId": 10,
    "roleId": 1,
    "userMessage": {"id": 20, "sender": "user", "content": "你好"},
    "assistantMessage": {"id": 21, "sender": "assistant", "content": "你好呀，喵。"},
    "usage": {"total_tokens": 120}
  }
}

SSE 流式协议

event: start
data: {"conversationId":10,"roleId":1,"userMessage":{"id":20,"sender":"user","content":"你好"}}

event: delta
data: {"content":"你好呀"}

event: done
data: {"assistantMessage":{"id":21,"sender":"assistant","content":"你好呀，喵。"},"usage":{"total_tokens":120}}

event: error
data: {"code":"CHAT_SERVICE_ERROR","message":"聊天服务暂时不可用"}

POST SSE 不能使用浏览器原生 EventSource，应使用 fetch 和 response.body.getReader() 读取。

GET/history 需要 JWT

GET /history?roleId=1&beforeId=20&limit=50
字段说明
roleId必填，角色 ID
beforeId可选，加载此 ID 之前的更早消息
limit默认 50，最大 100
{
  "success": true,
  "data": {
    "conversationId": 10,
    "roleId": 1,
    "messages": [{"id":20,"sender":"user","content":"你好","createdAt":"2026-06-11T02:00:00.000Z"}],
    "hasMore": true,
    "nextBeforeId": 20
  }
}

DELETE/history?roleId=1 需要 JWT

{
  "success": true,
  "data": {
    "conversationId": 10,
    "roleId": 1,
    "deletedCount": 12
  }
}
只清空当前 JWT 用户与指定角色的聊天。前端必须进行二次确认。

常用错误码

code前端处理
AUTH_REQUIRED跳转登录页
INVALID_TOKEN清除 Token 并重新登录
TOKEN_EXPIRED提示登录过期并重新登录
USER_DISABLED提示账号不可用
INVALID_INPUT提示参数错误
ROLE_NOT_FOUND刷新角色列表
DATABASE_ERROR提示稍后重试
QWEN_API_ERROR提示模型服务异常
CHAT_SERVICE_ERROR提示聊天服务异常

当前能力边界

  • 仅支持中国大陆手机号。
  • 没有刷新 Token、注销账号和退出登录服务端接口。
  • 每位用户对每个角色只有一份持续聊天。
  • 不支持自定义角色或多会话。
  • 图片不持久化。
  • 天气由模型自动调用，仅支持实时天气。
